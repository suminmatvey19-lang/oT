# Практикум по охране труда

Учебное адаптивное веб-приложение по четырём темам: исследование шума, вибрация и виброзащита, контроль защитного заземления, способы и средства пожаротушения.

## Запуск

Откройте `index.html` в современном браузере. Для установки как приложения и работы кэша офлайн запустите локальный веб-сервер (например, `python -m http.server 8000`) из этой папки и откройте адрес `http://localhost:8000`. Для доступа к микрофону, датчикам и геолокации браузер требует защищённый контекст (HTTPS или localhost).

## Внутри

- Учебный шумомер через микрофон (относительный уровень, не поверенное измерение).
- Вибрационный тренажёр на данных акселерометра устройства и ручном вводе.
- Калькулятор сопротивления защитного заземления по модели параллельных электродов.
- Сценарии выбора первичных средств пожаротушения.
- Установка на телефон как PWA и локальный офлайн-кэш.

Учебный материал не является заменой производственных измерений, поверенных приборов, инструктажа и локальных регламентов.
